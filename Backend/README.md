## Instalação e Execução

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar em modo desenvolvimento (hot-reload)
npm run dev

# 3. Iniciar em modo produção
npm start
```

O servidor sobe na porta **3001**: `http://localhost:3001`

> **Na primeira execução**, o SQLite cria o arquivo `banco_ponto.sqlite` automaticamente e insere o usuário administrador padrão:
> - **Usuário:** `admin`
> - **Senha:** `admin123`
