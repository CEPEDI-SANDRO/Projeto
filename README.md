## Como Rodar o Projeto

### 1. Iniciar o Backend (API)

```bash
cd Backend
npm install
npm run dev       # com hot-reload (nodemon)
# ou
npm start         # produção
```

A API ficará disponível em: **http://localhost:3001**

> Na primeira execução, o banco de dados `banco_ponto.sqlite` é criado automaticamente junto com todas as tabelas e o **usuário administrador padrão**:
> - **Usuário:** `admin`
> - **Senha:** `admin123`

### 2. Iniciar o Frontend

```bash
cd frontend
npm install
npm run dev
```

O frontend ficará disponível em: **http://localhost:3000**
